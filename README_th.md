# CAD-MCP Server (เซิร์ฟเวอร์ CAD Model Context Protocol)

[English](/README_en.md) | [中文](/README_zh.md) | [ไทย](/README_th.md)

## แนะนำโปรเจกต์

CAD-MCP คือบริการควบคุม CAD รูปแบบใหม่ที่ช่วยให้สั่งงานโปรแกรม CAD เพื่อเขียนแบบได้ด้วยคำสั่งภาษาธรรมชาติ โปรเจกต์นี้ผสานการประมวลผลภาษาธรรมชาติเข้ากับเทคโนโลยีระบบอัตโนมัติของ CAD ทำให้ผู้ใช้สร้างและแก้ไขแบบ CAD ได้ด้วยคำสั่งข้อความง่าย ๆ โดยไม่ต้องควบคุมหน้าจอ CAD ด้วยตนเอง

เวอร์ชัน 2.0 ได้รับการอัปเกรดทั้งหมดตามข้อกำหนด MCP ล่าสุด (FastMCP, structured output, tool annotations, progress notifications, Streamable HTTP) และมีเครื่องมือรวม 35 รายการ ครอบคลุมการสืบค้นข้อมูล การแก้ไข เลเยอร์ การจัดการแบบ บล็อก และการส่งผ่านคำสั่ง ซึ่งรวมกันเป็นวงจรการทำงานครบถ้วนแบบ "เขียนแบบ → ตรวจสอบ → แก้ไข"

## คุณสมบัติ

### ฟังก์ชันควบคุม CAD

- **รองรับโปรแกรม CAD หลายตัว**: รองรับโปรแกรม CAD หลัก ได้แก่ AutoCAD, GstarCAD (GCAD) และ ZWCAD
- **ฟังก์ชันเขียนแบบพื้นฐาน**:
  - วาดเส้นตรง
  - วาดวงกลม
  - วาดส่วนโค้ง
  - วาดวงรี
  - วาดสี่เหลี่ยมผืนผ้า
  - วาดโพลีไลน์
  - เพิ่มข้อความ
  - เติมลวดลาย (Hatch)
  - ใส่เส้นบอกขนาด
- **ฟังก์ชันสืบค้นข้อมูล (AI มองเห็นเนื้อหาจริงในแบบได้)**:
  - แสดงรายการเลเยอร์ทั้งหมด
  - แสดงรายการวัตถุ (entity) ใน model space (ส่งคืน handle ของวัตถุที่นำไปแก้ไขได้)
  - สืบค้นคุณสมบัติโดยละเอียดของวัตถุจาก handle (พิกัด/รัศมี/เนื้อหาข้อความ ฯลฯ)
  - จับภาพหน้าจอ CAD เพื่อดูตัวอย่าง
- **ฟังก์ชันแก้ไข**: ลบ, ย้าย, หมุน, ย่อ/ขยาย, คัดลอก, สะท้อน (mirror), offset, array (แบบเส้นตรง/แบบวงกลม), undo/redo
- **การจัดการเลเยอร์**: สร้างและสลับเลเยอร์ สืบค้นสถานะเลเยอร์
- **การจัดการแบบ**: สร้างใหม่ / เปิด / ปิด / บันทึกแบบ (DWG/DXF)
- **การทำงานกับบล็อก**: สร้าง แทรก และแสดงรายการบล็อก
- **การส่งผ่านคำสั่ง**: รันคำสั่ง CAD ใดก็ได้ผ่าน `send_command` (ทางออกสำหรับงานอื่น ๆ ที่เครื่องมือไม่ครอบคลุม)

### คุณสมบัติของโปรโตคอล MCP

- **Structured Output**: เครื่องมือทุกตัวส่งคืน `structuredContent` พร้อม `outputSchema` ที่ไคลเอนต์นำไปแยกวิเคราะห์ได้ทันที
- **Tool Annotations**: เครื่องมือสืบค้นข้อมูลถูกกำหนดเป็น `readOnlyHint` ส่วนการทำงานที่ทำลายข้อมูลถูกกำหนดเป็น `destructiveHint` เพื่อให้ไคลเอนต์ใช้กำหนดนโยบายการยืนยัน
- **Progress Notifications**: การทำงานที่ใช้เวลานาน (เปิด CAD, บันทึกไฟล์) จะส่งข้อความแจ้งเตือนไปยังไคลเอนต์
- **รองรับการสื่อสาร 2 โหมด**: `stdio` (ใช้ภายในเครื่อง ไคลเอนต์เดียว) และ `streamable-http` (ใช้ระยะไกล / หลายไคลเอนต์ใช้ CAD instance เดียวกัน)
- **รูปแบบข้อผิดพลาด**: ข้อผิดพลาดจากการตรวจสอบอินพุตจะส่งคืนเป็น tool error ทำให้โมเดลแก้ไขตัวเองได้

### ฟังก์ชันประมวลผลภาษาธรรมชาติ (อินเทอร์เฟซเดิม)

- **แยกวิเคราะห์คำสั่ง**: แปลงคำสั่งภาษาธรรมชาติเป็นพารามิเตอร์การทำงานของ CAD
- **จดจำสี**: ดึงข้อมูลสีจากข้อความและนำไปใช้กับวัตถุที่วาด
- **จับคู่คำสำคัญของรูปทรง**: รองรับการจดจำคำบรรยายรูปทรงหลากหลายแบบ
- **จับคู่คำสำคัญของการกระทำ**: จดจำการกระทำต่าง ๆ ทั้งการวาดและการแก้ไข

## ความต้องการในการติดตั้ง

### Dependencies

```
pywin32>=306       # รองรับอินเทอร์เฟซ Windows COM
mcp>=1.12,<2       # MCP Python SDK (FastMCP, structured output, Streamable HTTP)
pydantic>=2.0.0    # ตรวจสอบความถูกต้องของข้อมูล
Pillow>=10.0.0     # เข้ารหัส PNG สำหรับภาพตัวอย่างหน้าจอ
```

### ความต้องการของระบบ

- ระบบปฏิบัติการ Windows
- ติดตั้งโปรแกรม CAD แล้ว (AutoCAD, GstarCAD หรือ ZWCAD)
- Python 3.10 ขึ้นไป

## การตั้งค่า

ไฟล์ตั้งค่าอยู่ที่ `src/config.json` และมีการตั้งค่าหลักดังนี้

```json
{
    "server": {
        "name": "CAD MCP 服务器",
        "version": "2.0.0",
        "transport": "stdio",
        "host": "127.0.0.1",
        "port": 8000
    },
    "cad": {
        "type": "AUTOCAD",  
        "startup_wait_time": 20,
        "command_delay": 0.5
    },
    "output": {
        "directory": "./output",
        "default_filename": "cad_drawing.dwg"
    }
}
```

- **server**: ชื่อเซิร์ฟเวอร์ เวอร์ชัน และการตั้งค่าการสื่อสาร
  - `transport`: โหมดการสื่อสาร `stdio` (ค่าเริ่มต้น ใช้ภายในเครื่อง ไคลเอนต์เดียว) หรือ `streamable-http` (ระยะไกล / หลายไคลเอนต์)
  - `host` / `port`: ที่อยู่และพอร์ตที่รอรับการเชื่อมต่อในโหมด Streamable HTTP (เขียนทับได้ด้วยอาร์กิวเมนต์ `--host` / `--port` ทางบรรทัดคำสั่ง)
- **cad**: 
  - `type`: ประเภทโปรแกรม CAD (AutoCAD, GCAD, GstarCAD หรือ ZWCAD)
  - `startup_wait_time`: เวลารอให้ CAD เปิดเสร็จ (วินาที)
  - `command_delay`: เวลาหน่วงระหว่างการรันคำสั่ง (วินาที)
- **output**: การตั้งค่าไฟล์เอาต์พุต

## วิธีใช้งาน

### เริ่มต้นบริการ

```bash
# ตัวเลือกที่ 1: รันโดยตรง (ใช้ได้กับการตั้งค่า Claude/Cursor เดิมทั้งหมด)
python src/server.py

# ตัวเลือกที่ 2: ติดตั้งเป็นเครื่องมือ CLI
pip install -e .
cad-mcp

# ตัวเลือกที่ 3: รันด้วยการสื่อสารแบบ Streamable HTTP (ระยะไกล / หลายไคลเอนต์ใช้ CAD instance เดียวกัน)
python src/server.py --transport streamable-http --port 8000
# ไคลเอนต์เชื่อมต่อที่ http://127.0.0.1:8000/mcp
```

### เชื่อมต่อจาก MCP Client

เซิร์ฟเวอร์ใช้การสื่อสารแบบ `stdio` เป็นค่าเริ่มต้น จึงใช้การตั้งค่า JSON ชุดเดียวกันได้กับ MCP client ทุกตัว (Claude Desktop, Cursor, Windsurf, TRAE ฯลฯ) ให้เพิ่มลงในไฟล์ตั้งค่า MCP server ของไคลเอนต์ (เช่น `claude_desktop_config.json`, `mcp.json` ของ Cursor) และเปลี่ยนพาธเป็นของคุณเอง

```json
{
    "mcpServers": {
        "CAD": {
            "command": "python",
            "args": [
                # พาธจริงของคุณ เช่น:"C:\\cad-mcp\\src\\server.py"
            ]
        }
    }
}
```

สำหรับโหมด Streamable HTTP ให้ตั้งค่าไคลเอนต์ไปที่ `http://127.0.0.1:8000/mcp` แทน

### Service API

เซิร์ฟเวอร์มีเครื่องมือต่อไปนี้ (รวม 35 รายการ)

**เขียนแบบพื้นฐาน:**
- `draw_line`: วาดเส้นตรง
- `draw_circle`: วาดวงกลม
- `draw_arc`: วาดส่วนโค้ง
- `draw_ellipse`: วาดวงรี
- `draw_polyline`: วาดโพลีไลน์
- `draw_rectangle`: วาดสี่เหลี่ยมผืนผ้า
- `draw_text`: เพิ่มข้อความ
- `draw_hatch`: วาดลวดลาย Hatch
- `add_dimension`: ใส่เส้นบอกขนาดแนวตรง

**สืบค้นข้อมูล:**
- `list_layers`: แสดงรายการเลเยอร์ทั้งหมด
- `list_entities`: แสดงรายการวัตถุใน model space (ส่งคืน handle ที่นำไปแก้ไขได้)
- `get_entity_properties`: สืบค้นคุณสมบัติโดยละเอียดของวัตถุจาก handle
- `screenshot`: จับภาพหน้าจอ CAD เพื่อยืนยันผลการเขียนแบบ

**แก้ไข:**
- `erase_entity` / `move_entity` / `rotate_entity` / `scale_entity`: ลบ / ย้าย / หมุน / ย่อขยายวัตถุ
- `copy_entity` / `mirror_entity` / `offset_entity`: คัดลอก / สะท้อน / offset วัตถุ
- `array_linear_entity` / `array_polar_entity`: array แบบเส้นตรง / แบบวงกลม
- `undo` / `redo`: ย้อนกลับ / ทำซ้ำ

**จัดการเลเยอร์และแบบ:**
- `create_layer` / `set_current_layer`: จัดการเลเยอร์
- `new_drawing` / `open_drawing` / `close_drawing` / `save_drawing`: จัดการแบบ
- `create_block` / `insert_block` / `list_blocks`: ทำงานกับบล็อก
- `send_command`: รันคำสั่ง CAD ใดก็ได้ผ่านบรรทัดคำสั่ง

**อินเทอร์เฟซเดิม:**
- `process_command`: ประมวลผลคำสั่งภาษาธรรมชาติ

## โครงสร้างโปรเจกต์

```
CAD-MCP/
├── imgs/                # รูปภาพและวิดีโอ
│   └── CAD-mcp.mp4     # วิดีโอสาธิต
├── pyproject.toml       # การตั้งค่าแพ็กเกจ (pip install -e .)
├── requirements.txt     # Dependencies ของโปรเจกต์
└── src/                 # ซอร์สโค้ด
    ├── __init__.py     # ไฟล์เริ่มต้นแพ็กเกจ
    ├── cad_controller.py # ตัวควบคุม CAD (ชั้น COM: เขียนแบบ/สืบค้น/แก้ไข/จัดการแบบ/บล็อก)
    ├── config.py        # ตัวโหลดการตั้งค่าแบบ singleton
    ├── config.json     # ไฟล์ตั้งค่า
    ├── models.py        # โมเดล structured output (outputSchema)
    ├── nlp_processor.py # ตัวประมวลผลภาษาธรรมชาติ
    └── server.py       # ส่วนการทำงานของเซิร์ฟเวอร์ (FastMCP)
```
